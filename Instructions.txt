SOLAR GROVE — QUICK START

Install Python 3.10+ and run:
  pip install -r requirements.txt
  python game.py

Default controller: greedy pathfinding baseline (no machine learning).
Train PPO:
  python train.py --steps 500000 --seed 42 --output models/solar_ppo
Play with trained PPO:
  python game.py --agent ppo --model models/solar_ppo.zip
Compare controllers:
  python evaluate.py --model models/solar_ppo.zip --episodes 30

SPACE: pause/resume | R: restart map | N: next seed
TAB: cycle loaded controllers | +/-: speed | ESC: quit
E: fresh map editor; press again to run the edited map
In editor: 1 rock, 2 salvage, 3 erase; left-click a tile to paint.
Robot tiles are protected; robot count stays fixed for PPO compatibility.
The editor may create disconnected maps; benchmarks use connected maps.

Full technique, environment rules, training details and limitations: README.md
