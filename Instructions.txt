SOLAR GROVE — PRODUCTION CHALLENGE

Install Python 3.10+ and run:
  pip install -r requirements.txt
  python game.py --designer ppo

The bundled trained PPO policy chooses array deployment, direction and tilt.
Two robots execute its design using deterministic BFS navigation.

Press ENTER, type produce 1 kW, then ENTER to submit.
L: region | [ / ]: solar time | D: sunlight sweep
SPACE: pause | R: restart | ESC: cancel command or exit

Train a new policy:
  python train_array.py --steps 200000 --seed 42 --output models/array_ppo
Evaluate:
  python evaluate_array.py --model models/array_ppo.zip --episodes 200 --output runs/comparison
Play the new checkpoint:
  python game.py --designer ppo --array-model models/array_ppo.zip
Planner comparison:
  python game.py --designer planner

Full ML details and measured limitations: README.md and docs/ML_RESULTS.md
